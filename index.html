WAVE 3 · BETA · INVITE-ONLY

Dyktafon
live transkrypcja spotkań z AI

Nagrywaj rozmowy w przeglądarce. Dostajesz transkrypcję na żywo z rozpoznaniem osób, komentarz agenta z fact-checkiem, sync między urządzeniami i gotowe akcje w Google Suite.

Otwórz aplikację
dyktafon.vercel.app · PWA · Safari, Chrome · Mac, iPhone, Android
01

Transkrypcja

01.01

Live streaming

Speechmatics real-time. Partial i final chunki z merge policy — pełne zdania zamiast urywków.

  • PL / EN (per sesja)
  • Konfigurowalny max_delay 1–10s
  • Enhanced / Standard operating point
  • Zmiana parametrów w locie (auto-restart WS)
01.02

Rozpoznawanie osób

Automatyczna diarization do 10 mówiących. Speaker embeddings, kolor per osoba.

  • Inline aliasy — klik i wpisz imię
  • Retroaktywne przemianowanie wszystkich bąbli
  • Statystyki: słowa · czas · % wkładu
01.03

Edycja w locie

Dwie strefy: live (ostatnie 3, read-only, auto-scroll) i settled (edytowalne).

  • Klik na chunk → textarea, Cmd+Enter zapisuje
  • Sticky-bottom scroll — nie pauzuje live
  • IndexedDB backup audio lokalnie
02

Agent AI

02.01

Komentarze live

Claude Sonnet 4.6 albo Haiku 4.5. Automatyczne co 30s + button on-demand.

  • Dymki anchored do konkretnego fragmentu
  • Toggle on/off, przełącznik modelu w locie
  • Licznik tokenów + koszt per komentarz
02.02

6 osobowości

Wybierz kto komentuje twoją rozmowę. Każda persona z osobnym system promptem.

  • Hermiona — hard truth. Nazywa drift wprost, pyta „co dokładnie ustaliliście?" gdy rozmowa płynie ale nic nie zapadło.
  • Mira — principal engineer. Ukryte założenia, tradeoffy, „kto jest source of truth?", „co przy failure?".
  • Eleanor — UX/UI. Zawsze pyta „dla kogo i kiedy". Reaguje gdy dyskusja pomija odbiorcę.
  • George — neurotyk (Costanza). Opposite logic, wyciąga rzecz o której wszyscy myśleli ale nikt nie chciał powiedzieć.
  • Harvey — closer (Specter). „Co jest teraz do zamknięcia?", „jaka cena tej decyzji?", „kto ma leverage?".
  • Neutralny — rzeczowy, bez charakteru. Kluczowe punkty, otwarte pytania, bez oceny.
02.03

Fact-check z web

Sonnet + web_search weryfikuje twierdzenia (daty, cytaty, wydarzenia historyczne).

  • Per komentarz — button „Sprawdź"
  • Per claim w summary — re-check on demand
  • Werdykt: Potwierdzone / Obalone / Niepewne + źródła
03

Po Stop

03.01

Auto-podsumowanie

Sonnet analizuje transkrypt + statystyki i generuje pełne omówienie sesji.

  • Tytuł (3–8 słów, opisujący temat)
  • Streszczenie 2–4 zdania
  • Tagi tematyczne 3–8
  • Progress bars per uczestnik
03.02

Sugerowane akcje

Agent wykrywa akcje w rozmowie i podpisuje deep linki do Google Suite.

  • Kalendarz — event prefill (data, duration, details)
  • Gmail — draft maila (adresat, subject, body)
  • Docs — content w schowku, nowy dokument
03.03

Fact-check report

Do 5 kluczowych twierdzeń z rozmowy zweryfikowane w web.

  • Color-coded werdykt (zielony / czerwony / pomarańczowy)
  • Uzasadnienie + linki do źródeł
  • Re-check button per claim
04

Nawigacja i archiwum

04.01

Full-text search

Postgres FTS z GIN indexem po transkrypcie, tytułach i tagach. Debounce 300ms, wyniki z bold-highlighted snippet.

  • Accent-insensitive (wnętrze = wnetrze)
  • Składnia websearch: cudzysłowy, OR, -exclude
  • Badge „transkrypt" vs „meta"
04.02

Public share

Read-only link do sesji dla osób bez konta. Token-based, SECURITY DEFINER function bypassuje RLS w kontrolowany sposób.

  • Toggle w detail view — link do skopiowania
  • Bez autoryzacji, ale nie do zindeksowania
  • Revoke jednym kliknięciem
04.03

Export

Pełne dane sesji do lokalnego pliku — Markdown do czytania, JSON do dalszego przetwarzania.

  • Transkrypt z osobami + summary
  • Fact-check report z werdyktami i źródłami
  • Suggested actions + metadata
05

Wiele urządzeń, jedno spotkanie

05.01

Shadow view

Otwórz tę samą sesję na drugim urządzeniu — dostajesz live shadow z transkrypcją bez podwójnego nagrywania.

  • Supabase Realtime (postgres_changes)
  • Chunki, agent bubbles, speakerzy — auto-update
  • Wymuś zakończenie jak tamto urządzenie padło
05.02

WS reconnect

Speechmatics WebSocket sam się podnosi po zerwaniu. PCM buforowany lokalnie, wysyłany po reconnect.

  • Exponential backoff (1s / 3s / 9s)
  • Bufor do 60s audio
  • Wake Lock — ekran nie gaśnie w trakcie
05.03

Anti-halucynacje

AudioWorklet z RMS + ZCR gate przed wysłaniem chunku. Filtruje ciszę, szum, sygnał nie-mowy.

  • Progi konfigurowalne w Settings
  • Zero „you" i „thank you" z pustki
  • Force-stop dla zombie sesji z listy
06

Bezpieczeństwo i dostęp

06.01

Invite-only + tokeny

Nowe konta tylko z zaproszenia. Postgres trigger na auth.users blokuje signup spoza allowlisty. Admin generuje jednorazowe tokeny.

  • SECURITY DEFINER redeem_invite_token
  • Panel admina do zarządzania listą
  • Token wygasa po użyciu
06.02

Email + hasło

Klasyczny auth Supabase — działa identycznie w Safari, PWA i innych przeglądarkach. Reset przez link mailowy.

  • signInWithPassword — bez maili co logowanie
  • Sesja perzystuje między urządzeniami
  • updateUser({password}) do zmiany hasła
06.03

RLS + accounting

Każda tabela z Row-Level Security. Panel admina z tabelą kosztów LLM per user, per model.

  • llm_calls z automatyczną kalkulacją $
  • User widzi tylko swoje dane
  • Retry logic dla 5xx/429 od Anthropic
