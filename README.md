# dyktafon-landing

Landing page dla [dyktafon.vercel.app](https://dyktafon.vercel.app) — live transkrypcja spotkań z AI.

## Development

Otwórz `index.html` w przeglądarce lokalnie:

```
open index.html
```

## Deploy
